# 前端页面排版优化（2026-10-06）

## 问题与调整

- 小窗口顶栏挤压标题：375px 宽时标题内容宽 144px、可用宽 126px，出现截断；主题按钮实际高度为 30px。本轮在 640px 以下将品牌与操作区排为两行，主题按钮统一为 36px。
- 卡片、图表和页面背景层次接近：细化灰蓝正式主题与石板蓝监控主题，调整边框、卡片内距、数字和图标排版，保留实测、预测、回测、光伏各自的图表色与线型。
- 光伏未来预测主图排在历史回测之后：将未来主图移到指标后、回测前。
- 电价通过 CSS `order` 调换区块，视觉与键盘顺序不同：按“未来预测 → 历史回测 → 分小时明细”排列源码，移除 `order-1/2`。
- 历史分析公共长说明占用首屏：改为原生可展开说明，摘要保留在线快照与历史回测的区别，正文保留真实值回填延迟说明；调整标签按钮间距、图标和选中态。

修改限于 `frontend/src/index.css` 与光伏、电价、历史分析三个页面的展示结构。请求、轮询、日期选择、统计、模型、训练数据、认证和数据库均未改动。

## 后续排版细节修复

继续检查中确认系统状态页使用的进度条、模型卡片缺少对应样式，浏览器测得进度条与填充层高度为 0；日期回测提示框也使用了没有样式定义的旧类名。本轮恢复语义色进度条和模型卡片边界，回测提示框复用既有 `chart-tooltip`。

- 系统状态：初次加载复用卡片骨架，模型加载期间不提前显示空状态；系统信息随宽度切换内部列数，移除模型图标旁无条件的额外绿点。
- 气象页面：六个站点使用约 72px 高的摘要卡，保留温度、湿度、风速和选择功能；区域平均完整明细可展开，选中站点的完整数据继续显示在详情面板。中等宽度的第三个区域指标占满下一行。
- 历史分析：删除卡片内重复的水平缩进；提前量卡片到 xl 才排三列，回测指标在 lg 排三列、2xl 排五列；日期输入随主题切换。

本轮修改仅涉及前端展示。已有提前量 5 项、历史刷新 7 项、页面导航 8 项测试共 20 项通过，类型检查、构建通过。

浏览器确认：进度条恢复为 6px（模型条 4px），填充层可见；六张站点摘要卡约 72px，选中 Boston 后右侧详细值同步，区域平均可展开；1024px 下回测指标三列、提前量分组一列且内部无重复水平缩进；实际日期回测提示框具有不透明底色和边框；375px 系统状态无整体横向溢出。双主题已检查，临时窗口尺寸恢复。本轮未专门模拟首次请求长时间延迟、断网或全浏览器兼容场景。
