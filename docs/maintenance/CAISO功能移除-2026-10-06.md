# CAISO 太阳能预测应用功能移除

日期：2026-10-06。按用户要求移除“CAISO太阳能预测”的前端与后端应用功能，原 ISO-NE 光伏预测保留。

## 移除范围

- 前端：导航菜单、路由与页面、专用 Hook/类型/导出工具、3 个 CAISO API 方法、顶栏和侧栏的太平洋时区分支，以及专用页面测试。
- 后端：`/api/caiso-solar` 路由及其模型信息/历史回放接口、官方输入数据适配器、隔离推理入口和 worker、独立预测服务、应用注册与关闭时资源释放代码，以及 3 个专用测试文件。
- 共删除 13 个专用源码和测试文件，保留通用请求、认证、共享资源缓存、ISO-NE 数据获取和推理逻辑。
- 移除 `.env.example` 中已失效的 3 个 CAISO 应用配置示例；实际 `.env` 没有这些配置项，未修改实际配置或认证。
- 专用运行缓存 `backend/cache/caiso_solar/` 移出后端目录，38 个文件、1,812,343 字节的副本已逐件 SHA256 校验。

旧前端地址 `/caiso-solar-generation` 使用现有 404 页面，不再发起 CAISO 请求。后端 OpenAPI 不再注册任何 CAISO 接口。通用认证仍要求未认证业务请求提供凭据；不能仅凭未知路径返回的 401 判断旧功能仍存在。

## 保留范围

`experiments/caiso_pv/` 内的独立训练工程、TensorFlow 环境、模型、Scaler、训练数据和评价结果保持原位置。ISO-NE 的生产模型和原 `/solar-generation` 页面保留。论文原稿、更新排版版、素材及现有数据库内容未因本轮移除而删除。

旧接入验收和切页缓存文档加注移除日期，保留当时的实验/实现事实；当前 README 已改为仅列出现有应用功能。
