# 部署运行手册

## 必需资产

| 资产 | 路径 |
|---|---|
| 负荷模型权重 | `backend/models/tf_assets/tf_split_v1/load_best.weights.h5` |
| 电价模型权重 | `backend/models/tf_assets/tf_split_v1/price_best.weights.h5` |
| 负荷/电价 scaler | `backend/models/tf_assets/tf_split_v1/*_scalers.json` |
| 实时特征冷启动数据 | `backend/models/tf_assets/tf_split_v1/ca_features.parquet` |
| 光伏模型权重 | `backend/models/tf_assets/pv_v1/pv_v1_best.weights.h5` |
| 光伏 scaler | `backend/models/tf_assets/pv_v1/scalers.json` |
| 光伏冻结验收数据 | `backend/models/tf_assets/pv_v1/pv_tail.parquet` |

缺少任一生产模型资产时，后端严格启动模式会停止启动并报告缺失文件，不会生成替代预测。

## 环境

- Python 3.11、TensorFlow/Keras、MySQL、Redis、Node.js/npm
- `.env` 中配置数据库连接和 `AUTH_JWT_SECRET_KEY`

## 启动前检查

```powershell
python backend/scripts/check_runtime.py
```

检查通过后执行 `.\start.ps1`，或分别启动 FastAPI 与 Vite。

## 服务验收

1. `/api/system/status` 显示 3/3 个 TensorFlow 模型加载。
2. 负荷预测返回连续 24 个 MW 数值。
3. 电价预测返回连续 24 个 P10/P50/P90，且 P10 <= P50 <= P90。
4. 光伏预测返回连续 24 个值，夜间为 0。
5. 历史回测使用真实历史负荷/电价，并显示 MAE、RMSE、MAPE。

## 停止

启动脚本终端中按 `Ctrl+C`；如使用 Docker Compose，则运行 `docker compose down`。
