## 本轮只读离线诊断

新增 `MMXX/smart-grid/scripts/evaluate_prediction_candidates.py` 复用生产模型定义、现有权重和缩放器，只对已有验证/测试分区推理，不进行训练。推理分批展开窗口，本地 batch 不超过 32，不生成完整训练窗口数组。

本轮实际验证使用 Windows Python 3.11 / TensorFlow 2.16.1 CPU 环境。用户提供的 WSL Python 3.10 / GPU 环境未在本轮验证；该次调用的 WSL 默认入口与用户指定环境不同，未安装依赖或修改环境。

项目根目录运行（本地已配置的 TensorFlow Python 环境）：

```powershell
python MMXX/smart-grid/scripts/evaluate_prediction_candidates.py --batch 32
```

输出到 `MMXX/smart-grid/runs/prediction_audit_<UTC时间>` 的新目录；若指定 `--output`，必须仍位于该 runs 目录内且不能已存在。保存报告、逐窗口预测与参考值、目标小时以及来源文件 SHA-256，便于复现和核验。

电价只在验证集前 75% 的窗口拟合区间扩展值，并排除与后段验证共享目标小时的窗口。验证集后 25% 按“覆盖率更接近 80%，且区间评分改善”选择候选，然后才报告独立测试结果。中位数预测不调整，负电价保留，候选不会自动启用到线上。这是相关时间序列上的经验校准，不能宣称严格概率覆盖保证。

负荷诊断包括基于训练数据确定的高负荷阈值、86°F 以上高温、32°F 以下低温及节假日；没有样本的分组返回空指标。光伏参考值为 ISO-NE **估算的分布式光伏出力**，不是仪表实测；报告标明全天/白天误差、云量分组、完整日能量和峰值时间误差。

现有离线特征和季节性测试分区不等同于完整在线预测回放；负荷、电价天气输入也不能据此认定为当时发布的天气预报。正式训练或在线启用校准前，应补足预报批次与输入快照的留档，并评价未见季节和负电价场景。
