# 前端布局与操作优化验收（2026-10-03）

本轮保留已有冷灰蓝配色和藏蓝导航，仅优化前端布局、数据展示与键盘操作。保留已有模型、预测接口、认证、数据源和统计口径。

## 确认的问题与修改

- 指标卡片内部存在重复留白；窄屏四至五张指标卡片全为单列，曲线被推到较低位置。收紧共享卡片间距，360–639px 屏幕采用双列，奇数最后一张跨两列，保留数值和单位。
- 预测明细、峰值时刻、电价和光伏未来曲线只显示小时，跨日不易辨认。显示美东月日及小时，明细搜索同时匹配日期与时间，不改变预测目标时间或数值。
- 明细搜索无匹配时表格为空。增加明确的无匹配提示、清除按钮点击区域及匹配数量；加载和无可用预测分别说明状态。
- 历史表列数较多，缺少清楚的滚动入口。统一表格边界、数值对齐、分隔与交替底色；滚动区域可聚焦，支持方向键横向滚动；提示在桌面和窄屏均可见。模型及来源长字段换行，保留全部列。
- 主刷新按钮同时带有 `btn-primary` 和 `btn-ghost`，后者覆盖前者。共享刷新组件只保留一种按钮样式，主要刷新入口恢复蓝色。
- 用户菜单没有 Escape 关闭及切页关闭处理，移动侧栏关闭只移到屏外。补上账户菜单收起与焦点恢复；关闭的移动侧栏不再出现在键盘顺序或辅助技术树，桌面仍显示。
- 气象地图在单列布局下随宽度异常撑高。限制地图宽度为440px，缩小加载和空态留白；站点详情及状态可换行。
- 系统详情较早启用三列，长模型名与架构挤压。中等屏使用两列，宽屏三列，长文本换行。
- 运行热图说明与图格一起水平滚动。将说明置于滚动区域之外，复用工具栏与可聚焦滚动区。
- 错误提示统一为与工作台一致的边界、圆角及清晰文字，保留原始错误信息与重试入口。

## 验证结果

- TypeScript检查和生产构建通过。
- PageNavigation相关行为测试7项通过，包括账户菜单Escape、焦点恢复、切页关闭和移动菜单关闭等场景。
- 在1280px桌面宽度下，负荷页指标卡片从145px降至127px，绘图区起点从496px移至472px。该测量表示布局变化，不代表接口提速。
- 390px窄屏下，负荷及光伏指标采用双列，数值和单位未截断，奇数光伏卡片跨两列。
- 负荷明细按本次真实数据中的跨日日期 `10/04` 搜索得到4个小时；无匹配提示正常，清除后恢复12条分页明细。电价日期搜索同样得到对应4小时，图轴和表格均显示跨日日期。上述日期仅为验收输入，代码没有固定日期。
- 窄屏负荷表聚焦后按方向键，横向位置从0变为40；760px表格内容限制在307px滚动区域内，整页无横向溢出。
- 窄屏关闭侧栏的实际样式为 `display:none`，辅助技术树不再包含导航链接；桌面为 `display:flex`。
- 账户菜单Escape后收起，焦点恢复到“用户菜单”按钮；路由切换及滚动回顶部行为保留。
- 桌面及窄屏检查负荷、光伏、历史分析、气象和运行分析；桌面额外检查电价与系统状态。均未发现整页横向溢出。
- 气象页Boston站点选择及详情显示正常；地图桌面宽440px，窄屏约317px。
- 历史表1440px内容限制在933px滚动区域内，筛选标签及滚动提示可见。

开发服务已自动加载修改，在 `http://localhost:3000` 按 Ctrl+F5 刷新即可。下次仍从项目根目录运行 `./start`。
