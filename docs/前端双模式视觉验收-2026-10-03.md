# 前端双模式视觉验收（2026-10-03）

本轮仅调整前端呈现，保留既有代码修改、认证、预测时间口径、数据来源、模型权重和训练数据。未修改后端或开展训练。

## 确认问题与调整

- 原有顶栏、主体和卡片明度相近，界面缺少层次；改为统一藏蓝框架，正式模式使用中性灰蓝主体与汇总指标带，监控模式使用深蓝主体和独立指标卡。
- 顶栏增加“正式工作台 / 深色监控”切换，仅保存 `smartgrid.workspace.theme` 外观偏好，应用挂载前恢复；存储不可用时仍能在当前会话切换。
- 图表不再使用固定深色曲线和文字；实测、预测、回测、光伏保留不同颜色与线型。地图、提示框、历史表格、语义告警和键盘焦点均采用主题色。
- 总览整合重复状态行和底部服务卡，原预测生成时间与最近获取时间分别展示；独立负荷页下方保留回测误差，避免再次重复上方峰谷数值。
- 手机操作栏按“历史回看 / 刷新与导出”排列，保留导航关闭、用户菜单 Escape 和焦点恢复。

## 验证

- TypeScript 类型检查与生产构建通过；主题偏好和导航相关测试共 13 项通过。
- 使用已登录的本地真实数据检查：总览、负荷、电价、光伏、气象、历史记录、系统状态；负荷页同时检查 1440×900 与 390×844 两种宽度。
- 浏览器切换两种主题、重载后保留监控模式，实际曲线颜色与坐标、旧组件文字均正确解析。前端服务重启后再次确认主题与数据恢复；后端进程未重启。
- 负荷、电价、光伏、历史记录、系统页的主体区域无横向溢出；历史长表保持独立横向滚动区域。手机关闭导航为 `display:none`，切页返回顶部；用户菜单 Escape 后焦点回到触发按钮。
- 按最终色值计算，正文与面板对比度正式模式 10.77:1、监控模式 11.13:1；次要文字 5.50:1、7.29:1；主要曲线与绘图区对比度最低 4.23:1、7.99:1。
- 深色固定文字的遗漏与开发服务旧颜色定义已修复，前端单独重启，运行记录同步更新。

本轮未重新运行后端缓存过期、外部接口故障恢复、训练或模型精度验收；未测量接口速度或首次有效数据显示耗时，不宣称性能提升。未穷举所有历史分析子页和浏览器。

## 生效方式

当前本地前端已更新。浏览器使用 `Ctrl+F5` 刷新，在顶栏切换两种外观；以后按现有 `./start` 启动即可，无需重新训练模型、清理缓存或数据库。
