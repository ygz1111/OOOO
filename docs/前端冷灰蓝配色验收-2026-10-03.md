# 前端冷灰蓝配色验收（2026-10-03）

## 本轮范围

仅调整前端配色、展示布局、登录控件点击区域及负荷图时间刻度排列。保留已有页面结构、藏蓝导航、业务状态颜色和曲线颜色，保留预测接口、模型、训练数据及认证逻辑。

此前主体卡片、表单、图表浮层大量采用纯白，背景也接近白色；统一改为有层次的冷灰蓝工作台。复用现有卡片、图表、表单和数据状态组件。

| 用途 | 色值 |
| --- | --- |
| 主体背景 | `#d8e2ee` |
| 内容卡片 | `#e8eff7` |
| 图表、输入框和浮层 | `#f1f5fa` |
| 次级面板 | `#dfe8f2` |
| 页头、表头 | `#d9e4f0` |
| 边界 | `#b7c7d9` |
| 正文 / 次级文字 | `#243750` / `#52657c` |

全局主题提供 canvas、surface、ink、edge 语义颜色，兼容原有 dark 色阶。主要页面、登录、历史分析、按提前量统计面板与图表浮层均采用同一套表面颜色。保留黄色、红色异常提示与原始生成时间、估计输入说明。

## 读图与交互修正

- 图表背景比卡片稍亮，网格加深；实测、预测、回测和光伏继续使用不同颜色与线型。
- Recharts 运行时类名的背景样式放在不会被按源码裁剪的样式位置，保证生产构建保留图表底色。
- 实页发现负荷图未来时段没有时间标签：刻度列表先加入各小时刻度，再把窗口分界点追加到最后；`preserveStartEnd` 将该分界点作为末端而裁掉后续刻度。将刻度按横坐标升序排列后，未来刻度恢复。只改变刻度排列，不改变预测目标时间或数值。
- 窄屏下曲线标题、ET 标签及操作区允许换行；登录密码按钮点击区为 36×36，帮助和注册入口至少 32px 高。
