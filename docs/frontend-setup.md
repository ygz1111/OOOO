# 🚀 前端项目启动指南

## 环境准备

### 1. 安装 Node.js 和 npm
确保你已安装 Node.js (>=16) 和 npm (>=8)

```bash
# 检查版本
node --version  # >= 16.x.x
npm --version   # >= 8.x.x
```

### 2. 安装项目依赖
```bash
cd d:\GitHub\OOOOO
npm install
```

### 3. 启动后端服务
在另一个终端窗口启动后端API服务：
```bash
cd d:\GitHub\OOOOO\realtime_api
python app.py
```
确保后端服务运行在 `http://localhost:8000`

### 4. 启动前端开发服务器
```bash
npm run dev
```

前端将在 `http://localhost:3000` 启动

## 💡 使用提示

### 快捷键
- `F5` 或 `Ctrl+R` - 刷新页面
- `F12` - 开发者工具调试
- `Esc` - 关闭弹窗或侧边栏

### 数据刷新
- 系统每30秒自动刷新数据

## 🛠️ 故障排除

### API连接失败
1. 确认后端服务已启动 (`python realtime_api/app.py`)
2. 检查API地址配置 (`src/services/api.ts`)
3. 查看浏览器控制台错误信息

### 数据不显示
1. 刷新页面重新加载
2. 检查网络连接
3. 确认后端服务返回正确数据格式

### 样式问题
1. 清除浏览器缓存 (`Ctrl+Shift+R`)
2. 重启开发服务器
3. 检查Tailwind配置

### TypeScript编译错误
```bash
npm run type-check    # 检查类型错误
npm run build        # 强制重新编译
```
