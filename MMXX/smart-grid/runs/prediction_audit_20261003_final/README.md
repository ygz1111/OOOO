## 验证限制

- 负荷、电价沿用现有离线天气特征，不等于预测发出时的天气预报；光伏 day-1 天气表也不是所有任意发行时刻的完整在线回放。
- 重叠窗口重复使用参考小时，点数不是独立观测数量；区间扩宽仅是经验校准，没有严格概率覆盖保证。
- 当前测试分区没有冬季负荷、负电价样本，也没有覆盖夏令时转换日期，不能外推这些场景。
- 本轮没有 Shape/梯度/训练保存加载实验，因为未新增或训练模型；仅复用现有模型加载与推理。
- 用户约定的 WSL Python 3.10 / RTX 3050 GPU 环境未在本轮验证，未修改依赖或环境；正式训练按 Google Colab T4 约定执行。
